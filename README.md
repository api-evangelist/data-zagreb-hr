# data.zagreb.hr Official Open Data Portal (data-zagreb-hr)

data.zagreb.hr Official Open Data Portal is a open data portal open-data portal for Croatia running **CKAN**, exposing a standardized catalog API over ~199 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-zagreb-hr/refs/heads/main/apis.yml)
